# Public Assets

## Required Images

Place the following files in this directory before running the app:

| File | Description |
|------|-------------|
| `images/placeholder.jpg` | Default product image (400×400 recommended) |
| `icons/logo.svg` | ARTIC Marketplace logo |
| `icons/logo.png` | PNG version of logo |
| `favicon.ico` | Browser favicon |

## Banner Images

For the homepage carousel, upload banner images via the Admin → Banners panel.
Recommended size: **1500×500px**

## Product Images

Product images are uploaded via Admin → Products or served from the backend `/uploads/` directory.

## Fonts

The app uses the **Inter** font loaded from Google Fonts via `next/font`.
No additional font files needed.
